## 🎯 Objectif Principal

Thème WordPress développé pour un club de voyage avec un système de **Customizer** permettant de personnaliser facilement les sections héro et footer.

---

## 🎨 Customizer WordPress - Fonctionnalité Principale

Le thème se distingue par son **Customizer WordPress** qui permet de personnaliser facilement deux sections clés :

### 🌟 Section Héro - Accueil

_Panneau de personnalisation principal pour la section d'accueil_

#### 📝 Champs Disponibles :

- **Nom de l'auteur** : Texte personnalisable pour identifier l'auteur du thème
- **Adresse du club** : Coordonnées de localisation du club de voyage
- **3 Images de fond** : Carrousel d'images pour l'arrière-plan héro
- **Couleur du texte** : Sélecteur de couleur pour personnaliser le texte

### 🦶 Section Pied de Page

_Panneau de personnalisation pour le footer_

#### � Champs Disponibles :

- **Adresse complète** : Coordonnées détaillées du club
- **Numéro de téléphone** : Contact direct
- **Mission du club** : Description de la mission (zone de texte)

---

## � Installation Rapide

### Étapes d'Installation

1. Télécharger le thème
2. Extraire dans `/wp-content/themes/`
3. Activer le thème
4. **Configurer le Customizer** (étape cruciale)

### Configuration Customizer

1. `Apparence > Personnaliser`
2. Configurer "Section Héro - Accueil"
3. Configurer "Section Pied de page"
4. Publier les modifications

### Technologies Utilisées

- **PHP** : Logique serveur et Customizer
- **WordPress** : CMS et API
- **JavaScript** : Carrousel et interactivité
- **SCSS** : Styles modulaires
